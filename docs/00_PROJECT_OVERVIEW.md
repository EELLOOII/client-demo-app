# KQ Emporium

## Project Overview

KQ Emporium is a modern business website combined with an administration portal.

The objective is to allow customers to:

- Browse products
- Request quotations
- Send inquiries
- View promotions
- Read company news

Administrators can:

- Manage products
- Manage inventory
- Handle customer inquiries
- Prepare quotations
- Publish promotions
- Publish news
- Manage users

---

## Current Phase

Frontend MVP Prototype

The purpose of this phase is to build a high-quality UI prototype.

There will be:

- No backend
- No authentication
- No database
- No API

All pages should use mock data.

---

## Goal

Deliver a client-ready prototype that looks like a production application.
