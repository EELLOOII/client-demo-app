# AI Development Instructions

You are contributing to the KQ Emporium frontend project.

General Rules

- Follow the project folder structure.
- Use TypeScript exclusively.
- Prefer Server Components unless client-side state is required.
- Use shadcn/ui components before creating custom ones.
- Use Tailwind CSS for all styling.
- Avoid inline styles.
- Keep components under approximately 200 lines when practical.
- Extract reusable UI into the components directory.
- Place feature-specific components within their respective feature folders.
- Use mock data only.
- Do not create API calls.
- Do not implement authentication.
- Do not add backend logic.
- Do not introduce libraries unless necessary.
- Follow the design system and coding standards documented in the `docs` folder.
